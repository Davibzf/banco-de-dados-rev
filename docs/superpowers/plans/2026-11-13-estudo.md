# Site de estudo - Implementation Plan

**Goal:** entregar site móvel com 500 questões e explicações, código no GitHub e publicação Vercel.
**Architecture:** arquivos estáticos em public; banco JSON gerado e validado por Python; funções puras de sessão em core.js; interface em app.js; progresso local.
**Tech Stack:** HTML, CSS, JavaScript, Python sqlite3 para verificar resultados; Node test; Playwright apenas para verificação.
**Spec:** ../specs/2026-11-13-estudo-design.md

## Global Constraints
- 500 questões; 180 fáceis, 200 médias, 120 difíceis.
- Cinco alternativas únicas, explicação e assunto em toda questão.
- Não publicar os PDFs; sem backend, cadastro ou segredos.
- Usar GitHub e Vercel conforme pedido; executar diretamente, sem delegar.

## Review Focus
- Nenhuma questão no filtro: apresentar estado vazio e retorno.
- localStorage inválido ou indisponível: não perder funcionamento, exibir limite de persistência.
- Clique duplo: uma tentativa por questão e controle após confirmação.
- Voltar/recarregar: restaurar sessão e alternativas, sem trocar resposta.
- Celular estreito: código e tabelas rolam internamente, sem overflow da página.
